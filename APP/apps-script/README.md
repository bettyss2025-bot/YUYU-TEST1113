# 旅伴 roam 共用版

Google Apps Script 提供網頁和資料服務。旅伴只需開啟私人邀請連結，就能新增或修改旅伴、每日行程及支出。主辦人可以建立多個空白旅程、編輯名稱和日期，以及產生、更換或撤銷各旅程的連結。

## 主辦人首次部署

1. 用具編輯和部署權限的 Google 帳號開啟指定的 [Google 試算表](https://docs.google.com/spreadsheets/d/15epmkeXdkwjIb7GTVmbLhcW2gHkmyBIxH_Yl1zUzPWM/edit)。按右上角「共用」，將「一般存取」改為「限制」並儲存。如果存取權繼承自上層，請在 [Drive 資料夾](https://drive.google.com/drive/folders/14E8rBxt7SFXybNSS753DmnuZRCYOaGjB) 處理該權限。如果試算表曾「發布到網路」，也請在「檔案 → 共用 → 發布到網路」停止發布。旅伴無需任何試算表或 Drive 權限。
2. 在既有 Apps Script 專案中更新這四個檔案。程式檔為 `Code.gs`，HTML 檔為 `Index.html`、`Style.html`、`Client.html`。Apps Script 編輯器會自動加副檔名，建立 HTML 檔時只輸入名稱。若既有專案另有 `doGet`、`doPost` 或讀寫資料的前端可呼叫函式，先檢查函式用途和權限。正式共用版的入口為 `doGet` 和 `roamRpc`，舊有可匿名讀寫旅程的入口也須停用。
3. 在左側齒輪「專案設定」勾選在編輯器中顯示 `appsscript.json`。檢查並套用本目錄的執行環境與 OAuth 權限。如果原專案還有其他功能，保留其所需的 manifest 設定。
4. 回編輯器，儲存後在函式選單選 `setupRoam_`，按「執行」，從 Google 授權畫面選擇擁有試算表的帳號並授權。初始化會新增 `Roam_旅程`、`Roam_旅伴`、`Roam_行程`、`Roam_支出` 分頁。如果同名分頁有資料，程式會檢查欄名，原有資料保持原樣。
5. 按「部署 → 管理部署作業」，選既有網頁應用程式，按鉛筆，將版本切為「新版本」。在網頁應用程式設定中，執行身分選「我」，存取權選允許**未登入使用者**的「所有人」。按「部署」，複製顯示的 `/exec` 網址。若帳號政策未提供允許未登入使用者的選項，需要允許該選項、且能存取試算表的部署帳號。
6. 到「專案設定 → 指令碼屬性」，複製 `ROAM_ORGANIZER_KEY` 的值。在上一個步驟的網址後加上 `#organizer=` 和該值，用自己的瀏覽器開啟並加入私人書籤。只把頁面「邀請」分頁產生的旅伴連結分享出去。主辦人網址可以管理所有旅程，請存於自己的書籤或密碼管理器。

之後更新程式時，在「管理部署作業」為同一部署發行新版本，可沿用原 `/exec` 網址。要維持已發出的邀請，請保留既有的指令碼屬性和旅程分頁中的邀請版本。

## 分享與撤銷

開啟主辦人網址，選「建立旅程」或開啟已有的旅程。在「邀請」按「產生邀請連結」後複製連結。再次開啟「邀請」可以取得目前有效的連結。選「更換」會立即停用原連結並產生新連結。選「撤銷」會停用目前的連結。旅伴彼此共用同一個旅程連結。

在試算表中可直接修改名稱、時間、日期、地點、備註及支出金額。金額使用數字，單位是元。日期使用 `YYYY-MM-DD`，時間使用 24 小時制 `HH:mm`。請保留標題列、旅程 ID、各列 ID、付款旅伴 ID 及邀請版本。表格中現有的其他分頁可繼續使用。

GitHub Pages 版仍使用原瀏覽器的本機儲存。共用版從空白開始，沒有自動複製舊版瀏覽器中的示範或個人資料。要搬移實際使用過的資料，先取得原裝置上的資料副本。帳本可從原版匯出 Excel。

## 驗收

`npm test` 在 `APP` 內執行。Apps Script 測試使用記憶體試算表。若需重跑雙瀏覽器模擬，在 `APP` 安裝暫用測試套件並指定本機 Chromium 路徑。

```sh
npm install --no-save --package-lock=false playwright-core
CHROMIUM_PATH=/usr/bin/chromium node tests/browser-acceptance.mjs
```

正式驗收須使用 `/exec` 產生的有效邀請，以兩個各自未登入 Google 的瀏覽器開啟。第一個新增一位旅伴、當天行程和一筆支出。第二個重新整理後確認三筆資料、代墊金額和總支出。在同一份 Google 試算表的三個 Roam 分頁確認資料，將該支出金額改成另一個數字，再回第二個瀏覽器重新整理確認。最後在未帶邀請及撤銷後的網址驗證無法讀取及寫入。可以為驗收建立獨立旅程並在結束後撤銷其邀請。

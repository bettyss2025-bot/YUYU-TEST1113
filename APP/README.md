# 旅伴 roam

以台灣旅行為題的手機優先互動網頁原型。無需安裝套件、帳號或付費金鑰。

## 啟動

在本目錄執行 `node server.mjs`，開啟 http://localhost:5173 。需要 Node.js 20 以上。停止伺服器用 Ctrl+C。測試：`node --test tests/finance.test.mjs`。有 npm 的環境亦可使用 `npm start`、`npm test`。

同一 Wi-Fi 的手機可使用電腦區域網路 IP 加上 `:5173`（需作業系統允許連線）。不同裝置的本機資料不共用。不要直接雙擊 HTML，ES module 需透過 HTTP 載入。

## 已實作

- 探索頁已改為附官方來源及查核日期的內容快照：近期活動、經典景點、關鍵字搜尋、縣市／行政區篩選、實景照片與授權。六個經典地點逐一核對實景照片，活動照片未核實時用日期卡呈現；完整來源見 EXPLORE-SOURCES.md。沒有即時搜尋 API 或即時人氣排行。
- 行程頁（`/#itinerary`）：按旅程日期切換每日時間軸，新增／編輯／移除活動，選填起訖時間與備註、連結收藏地點、手動上下排序、完成標記、重疊時間提醒；儲存在各旅程本機資料內，不影響帳本金額。台南示範旅程提供完整三日提案，含具體景點、餐點方向、交通緩衝、雨天備案、地圖搜尋與官方資訊連結。所有示範成員可編輯行程，尚無遠端同步。
- 旅程建立／編輯／刪除、封面上傳、跨縣市文字、日期與預算；本機旅伴管理及示範角色權限。
- 支出、共同收入、連結原支出的退款、照片與備註、付款方式、地點關聯、編輯刪除、日期／類別／成員篩選。
- 平均與自訂分攤、付款人可不參與分攤、退款與部分還款、結清建議、每日花費與分類統計。
- 台北、台中、台南、高雄、花蓮示範地點、行政區與類型篩選、列表／可拖曳縮放地圖、收藏指定旅程、想去／已去、自訂地點與外部導航。
- 旅程照片回顧、相關帳目與 Excel（.xlsx）匯出，含收支明細、還款紀錄及旅程總覽。匯出目前旅程全部資料，不受畫面篩選影響；金額與日期保留型別，文字不作為公式執行，離線也可產生檔案。
- localStorage 保存，儲存中、成功、空白、表單驗證、容量不足及其他分頁更新警告。

## 原型界線與規則

這是本機示範，沒有登入、遠端資料庫、真實邀請或多人同步。角色切換僅模擬權限，不能視為資料安全機制。邀請碼清楚標示不能跨裝置加入。地圖為自行繪製示意圖，沒有精確座標與真實圖磚；外部 Google Maps 搜尋需自行核對地點。

預載四人台南三天兩夜資料，包括多人代墊、自訂分攤、非分攤人代墊、共同收入、退款和部分還款。地點文字與照片皆為示範；Unsplash 情境圖非實際店家照片，不提供即時評分與營業資訊。照片與 Google Fonts 需網路，字體有系統備援。照片上傳限 JPG、PNG、WebP、單張 1 MB；localStorage 容量有限，清除瀏覽器資料會遺失紀錄。

金額以整數「分」運算，輸入最多兩位小數。平均分攤的尾差依選取成員顯示順序逐分分配。退款按同一原支出累計退款總額，以原分攤比例及最大餘數法分配（同餘數依原成員順序），比例乘法使用 BigInt，避免多次小額退款造成尾差重複分配。退款不可超過原支出；已有退款的原支出須先移除退款，才能修改金額／付款人／分攤。個人已付款、應負擔會扣除退款，餘額再納入還款。所有成員餘額合計為零。

共同收入／基金只抵減預算，不視為某個人的代墊款、不分配個人分帳。原型未提供共同基金支用或分配流程；若由個人先付款，照實記錄代墊，不能再把同筆基金分配重複記帳。此規則在收入、帳本與分帳頁有提示。還款不計入旅遊收入／支出。

## 架構

- `finance.js`：獨立純計算函式，可直接用 Node.js 測試。
- `data.js`：示範旅程、地點與情境圖片。
- `services.js`：本機 repository、探索資料來源及地圖供應者介面，供日後替換。
- `app.js`：畫面、表單、示範角色權限、事件及示意地圖操作。
- `style.css`：繁體中文雜誌風格與手機斷點；`server.mjs` 為本機靜態伺服器。

目前用 revision 與 storage 事件偵測另一分頁的更新，發現差異會阻擋儲存並要求重新整理，避免一般過期編輯覆寫。這不是原子交易，極短時間同時寫入仍可能競爭，因此不宣稱真實同步。表單儲存期間停用提交並使用唯一紀錄 ID，避免一般連點重複送出。

## 真實服務下一步（均尚未啟用）

1. 後端：新增登入、Trip／Membership／Record／Repayment／SavedPlace 資料表，所有讀寫在伺服器檢查旅程成員權限；建立者管理旅程成員，紀錄作者才能改刪自己的帳目。不可信任前端 role。
2. 同步：以每筆紀錄 version + compare-and-swap 拒絕過期編輯（409），顯示前後差異讓使用者解決；用 idempotency key 與資料庫唯一約束去重；即時訂閱變更。失敗保留待同步草稿、明確顯示未同步與重試，不靜默覆蓋。
3. 金額與還款：將相同純計算規則放到後端，資料庫使用整數分；退款上限和還款檢查在交易內完成。邀請碼需具有效期、雜湊及撤銷機制。
4. 地圖：替換 `mapProvider` 與示意 renderer，使用實際經緯度、合法圖磚來源及標示來源；搜尋／圖磚／店家資料／圖片各自遵守供應者政策。不將公用免費圖磚視為無上限服務。
5. 部署：可將靜態檔案部署至靜態主機，後端另接託管資料庫與物件儲存。正式帳號、方案、流量與費用需先確認；本次未建立帳號、啟用計費或部署。私密金鑰只放伺服器環境變數。
6. 真實同步驗收需兩個獨立登入環境測試更新、未授權隔離、衝突、斷線重試與重複提交；目前尚未進行。現已加入 manifest、service worker 與 PWA 安裝設定；手機實機安裝待 HTTPS 部署後驗證。完整說明見 MOBILE-APP.md；原生 APK／IPA 尚未打包。

## 驗證紀錄

Node 計算測試涵蓋小數解析、無法整除平均分攤、付款人不分攤、自訂金額合計、比例退款、收入／部分還款、範例結清與大量尾差案例。瀏覽器檢查與結果另見交付訊息；不將單元測試當作真實同步驗證。
